# 已知限制

## Phase 2 遗留

- 旧版二进制 XLS 不解析，需另存为 XLSX。
- 图片与扫描 PDF 没有 OCR；明确规划为 Phase 2.1。
- PDF 只保证页码和文本，不重建不可靠表格。
- Excel 不复制完整视觉样式，不执行公式计算，只读取文件已有缓存结果。
- DOCX 不解析图片、批注、修订、脚注、页眉页脚和嵌入对象。
- Step 4 表格界面预览前 60 行、30 列；全部受上限保护的非空单元格仍保存为 ParsedBlock。
- 项目 JSON 备份包含原始文件，但暂不包含 ParsedDocument/Candidate store；恢复后可从原文件重新解析。
- 项目与候选位于不同 store，不能形成跨 store 的单一原子提交；稳定实体 ID 使确认重试保持幂等。
- 数据只保存在当前浏览器，清除站点数据会删除本地项目、文件及解析结果。

## Phase 3 范围（本轮未启动）

- 真实 LLM Provider；
- 语义事实/指标抽取与跨文档理解；
- RAG、向量检索或知识库；
- AI 事实判断、披露充分性判断或合规判断；
- 后端 API、PostgreSQL、云对象存储、账号权限与多人协作。

所有 Phase 3 能力仍必须遵守人工确认、来源追溯和不自动改写正式正文的既有约束。
