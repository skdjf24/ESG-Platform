# GB/T 4754 行业分类数据

- 标准：GB/T 4754-2017《国民经济行业分类》，含 2019 年第 1 号修改单。国家标准信息公共服务平台将其标为现行，并注明文本附第 1 号修改单。
- 官方原文：[国家统计局修订版 PDF](https://www.stats.gov.cn/sj/tjbz/gmjjhyfl/202501/P020250116506795831658.pdf)；[国家标准信息公共服务平台](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=A703F0E23DD165A5A1318679F312D158)；[修改单实施通知](https://www.stats.gov.cn/sj/tjbz/gjtjbz/202302/t20230213_1902779.html)。
- 数据整理日期：2026-11-17。运行时数据为 [`lib/industry/gbt4754-2017-amended.json`](../../lib/industry/gbt4754-2017-amended.json)，每条含代码、名称、层级和上级代码。
- 数量：20 门类、97 大类、473 中类、1382 小类，共 1972 条；与[国家统计局公布的四级数量](https://www.stats.gov.cn/zs/tjws/tjbz/202301/t20230101_1903769.html)一致。代码唯一，父级关系由回归脚本验证。

整理方法：以[公开的 2017 版结构化转录](https://github.com/ramwin/china-public-data/blob/master/%E5%9B%BD%E6%B0%91%E7%BB%8F%E6%B5%8E%E8%A1%8C%E4%B8%9A%E5%88%86%E7%B1%BB/%E5%9B%BD%E6%B0%91%E7%BB%8F%E6%B5%8E%E8%A1%8C%E4%B8%9A%E5%88%86%E7%B1%BB_2017.json)作为录入底稿，逐项与国家统计局修订版 PDF 可提取文本核对，校正转录中截断的名称和修改单涉及的名称，并新增修改单中的 `9233 人民检察院`。底稿 SHA-256 为 `71235531967dc01f5405f6beb162fad92ef012f517a94b854eb75769581b8f0a`。第三方转录不是标准依据；以上国家统计局 PDF 才是标准依据。

PDF 文本抽取会合并相邻行。1972 个名称均能在官方 PDF 的分类表或附录文本中找到。此前有 43 个代码与名称不能通过首次抽取结果的**同一行**自动配对；2026-11-18 已逐项对照国家统计局官方分类表、分类注释或目录，并核对仓库 JSON，43 项匹配、0 项不匹配。核对清单和补充官方来源见[43 项代码与名称复核](./gbt4754-43-pair-review.md)。这不等同于对全部 1972 项的人工逐项校对。分类数据可用于检索和选择，不能据此推定企业披露义务。

旧项目可能保存 `C26`、`C27` 等“门类字母 + 大类数字”代码。系统读取时解析为标准大类 `26`、`27`，展示完整路径；未经用户选择不会重写旧代码。新增选择采用标准数字代码，并同时保存 `primaryIndustry` 的名称、层级、上级代码及独立的 `otherIndustries` 集合。
