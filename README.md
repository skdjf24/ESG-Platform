# ESG Disclosure Platform

ESG 报告编制网站的第一版前端原型。项目以一个虚构示例企业“华澜新材料股份有限公司”和其 2025 年度 ESG 报告为主线，展示从企业基础画像、实质性议题评估、披露框架与报告大纲，到资料收集和事实库的核心工作流。

当前版本使用本地模拟数据，不接入真实 AI、文件存储或后端接口。

## 技术栈

- Next.js 16（App Router）
- React 19
- TypeScript 5（严格模式）
- Tailwind CSS 4
- Lucide React 图标
- ESLint 9

## 本地启动

建议使用 Node.js 20.9 或更高版本。

```bash
npm install
npm run dev
```

开发服务器启动后访问 `http://localhost:3000`。

生产构建与运行：

```bash
npm run build
npm run start
```

## TypeScript 数据类型

基础类型位于 `lib/types/esg.ts`，目前覆盖：

- 企业、报告项目和八步流程状态
- 历史资料与来源类型
- ESG 议题及财务/影响重要性评分
- 披露要求、系统建议与用户确认的适用性
- 报告章节及年度资料需求
- 建议责任部门、实际责任部门与资料收集状态
- AI 规整示例结果
- 企业事实、原始文件和页码/工作表/单元格级来源关联

示例数据统一位于 `lib/data/mock-data.ts`，页面组件从该文件读取，便于后续替换为 API 数据。

- 项目编制进度、当前步骤和下一步建议

- 八步侧边导航及当前步骤高亮
- 桌面侧边栏、平板抽屉导航与响应式内容区
- 项目进度、保存状态、上一步/下一步导航

- 议题搜索、分类筛选及纳入/移出
- 评估方式选择与参与范围展示
- 财务重要性、影响重要性评分表
- 双重重要性矩阵
- 重点议题结果及用户确认交互

### Step 3：构建披露框架与报告大纲

- 披露要求矩阵、框架筛选和搜索
- 系统建议与用户适用性确认分离
- 报告目录、章节选择与章节编辑区
- 本年度 ESG 报告所需资料清单

- AI 资料规整前后对照及人工确认
- 企业事实库与原始文件、工作表/单元格、页码关联

## 模拟功能说明

以下交互用于产品原型演示，不会写入后端或产生真实业务结果：

- 首页新建报告表单和项目统计
- 所有企业、议题、披露要求、资料、事实及来源数据
- 历史报告和资料文件上传
- 在线资料补充
- 议题增删、评分方式切换、适用性及重要性确认
- 责任部门调整、草稿保存和保存状态
- AI 资料解析与规整结果

所有 AI 结果在界面中明确标注为“示例 AI 规整结果”，需要人工确认后才表现为可进入事实库。项目没有调用真实 AI 接口，也没有 API 路由或外部数据请求。

## 业务约束

- 平台不自动判断企业是否具有强制披露义务；上市身份仅作为企业信息记录。
- 实质性议题的重要性结论由用户复核并确认。
- 披露要求的适用性由用户逐项确认，系统建议不是最终结论。
- 资料责任部门仅由系统建议，用户可以调整实际责任部门。
- 支持沿用企业现有 Excel 收集资料，不提供独立模板生成模块。
- 尚未收集的资料只显示“待收集”等流程状态，不预判为数据缺失。
- AI 模拟结果必须人工确认。
- 企业事实保留与原始文件及具体定位信息的关联。
